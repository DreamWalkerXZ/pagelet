# Reserve the underscore namespace for service endpoints

Use `/<slug>` for public reading, `/_/raw/<slug>` for raw Markdown, `/_/api/v1/*` for APIs, `/_/app/*` for login and management, `/_/openapi.json` for the public OpenAPI specification, and `/_/assets/*` for embedded assets. Deliver the API, raw access, and OpenAPI specification in phase one, with reading and management interfaces and their assets in phase two.
